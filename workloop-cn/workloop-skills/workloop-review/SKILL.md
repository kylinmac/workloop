# Workloop 独立审查

把 `../workloop/assets/templates/review.md` 复制到 `.workloop/loops/<id>/review.md`。如果你参与过实现，不得执行本审查。

只读取 `spec.md`、`plan.md`、`git diff <base_commit>..HEAD`、引用的原始证据和匹配源码。执行者的会话叙述不能作为证明。

1. 检查每个 AC 都有工作项。
2. 检查差异实现了 AC 的真实行为，而非仅有同名符号。
3. 检查每条证据指向真实、新鲜且匹配验证方法的输出。
4. 检查假设分类和关闭证据，并查找已拒绝假设仍残留的影响。
5. 检查差异没有超出意图和活动工作项范围。
6. 检查最大风险和每个契约都有实质验证。

独立重跑一到两个关键验证，记录外部审查者锚点和实际结果。

结论只能是 `pass` 或 `fail`。失败时列出每个问题及返回位置：实现或证据问题返回 `executing`，意图或假设问题返回 `clarifying`。通过时，只有真实、可复用失败且能形成可执行预防检查，才建议新增记忆。
