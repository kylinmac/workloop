# Workloop 错误记忆

项目首次需要 Workloop 状态时，才从 `../workloop/assets/templates/memory.md` 创建 `.workloop/memory.md`。审查通过后更新；没有合格教训就不新增记录。

只有同时满足以下条件，教训才能进入记忆：

1. 来自真实失败或独立观察到的缺陷；
2. 未来任务可能再次触发；
3. 触发条件足够具体，可以在行动前匹配；
4. 预防措施是可执行检查或精确审查断言。

最多保留 20 条。新增前先合并相同根因、删除最久未触发条目，或把重复预防检查升级为测试、Lint、CI 或 Hook 后从记忆中移除。

拒绝“认真验证”一类口号、没有可复用触发条件的一次性事故，以及只要求 Agent 声明更多状态的教训。
