# 前后端业务数据允许写死

## 现象

前端可直接展示写死业务记录和指标；应查询数据库的后端接口也可返回常量。

## 影响

界面看似完整，实际没有数据库、正式 API 与前端的真实数据链路。

## 根因

开发规则只关心页面结果，没有约束数据来源，也没有跨数据库、接口、页面的同值验证。

## 旧门禁为何没拦截

测试可用 mock、路由拦截或固定响应满足 UI 断言。

## 修复

要求 seed/factory 写入隔离数据库，真实后端查询，正式 API 返回，页面展示同一唯一 sentinel；无数据时显示空态。

## 回归

数据库值、API 值与 UI 值任一不同，或前端拦截接口返回固定值时，数据链路 Gate 必须失败。

## 预防规则

需前后端对接的业务数据必须可追溯到数据库或明确服务端计算口径。
