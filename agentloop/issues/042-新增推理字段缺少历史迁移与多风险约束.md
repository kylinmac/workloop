# 新增推理字段缺少历史迁移与多风险约束

## 症状

活动 Loop 可能已经是 control v2，却缺少 `assumptions`、`decision_records` 或 `risk_driver`；单一风险路由也无法表达必须同时处理的次要风险。

## 根因

推理控制字段在既有迁移版本之后加入，迁移命令只识别旧分类与验收结构；路由模型只保存一个风险，supporting flow 与验证义务没有受控来源。

## 修复

扩展 `migrate-v2`，识别缺失的推理字段并初始化数组，清空旧路由、退回澄清阶段并强制重新路由。`risk_driver` 增加 `secondary_risks`；每个次要风险必须映射到其对应 supporting flow 或明确验证义务，主风险仍唯一决定主流程。

## 回归

覆盖旧活动 Loop 字段迁移、迁移后强制风险重路由、两类次要风险映射和无效映射拒绝。
