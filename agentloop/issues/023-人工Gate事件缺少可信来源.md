# 人工 Gate 事件缺少可信来源

## 现象
CLI 接受任意 actor、source 和 source event ID。
## 影响
Agent 可把自报文本冒充人工批准。
## 根因
本地控制程序没有宿主身份或签名能力，却把来源字段当成证明。
## 旧门禁为何没拦截
只校验字段存在，没有校验 Gate 状态和事件认证级别。
## 修复
人工批准默认要求宿主认证事件；无认证能力时失败关闭。CLI 只允许拒绝或导入已认证事件，并限制 Gate 所属状态。
## 回归
任意自报批准和终态批准失败；认证测试事件在正确状态通过。
## 预防规则
身份字段不等于身份凭证，必须明确发行方和验证方法。
