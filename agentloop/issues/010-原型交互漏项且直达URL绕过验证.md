# 原型交互漏项且直达 URL 绕过验证

## 现象

原型要求点击需求后按状态进入不同工作阶段，实现矩阵和用户旅程漏掉该交互；自动化直接访问目标 URL 截图，33 个断言仍全部通过。

## 影响

实际实现把所有行统一打开澄清抽屉，入口行为错误却被视觉和自报覆盖判定掩盖。

## 根因

矩阵是唯一覆盖来源，原型源代码没有独立行为清单；测试只验证声明过的交互，形成封闭自证循环。

## 旧门禁为何没拦截

矩阵、旅程、flow、Evidence 都复制同一份漏项，集合彼此一致；直接 URL 能代替真实点击路径。

## 修复

控制程序扫描原型生成带源摘要的行为清单；矩阵必须一一映射全部行为和导航分支；导航 Evidence 必须从起始路由经真实用户操作到达目标，直达 URL 不计覆盖。

## 回归

原型含点击事件和多状态跳转时，漏掉任一行为、分支、旅程或真实导航边都必须阻止 developing/verified。

## 预防规则

验收覆盖必须有独立于实现矩阵的来源基线，测试不得以目标页可访问替代入口因果链。
