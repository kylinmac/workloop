# AgentLoop 整体流程插件化

## 目标与完成标准
- 最终目标：把本仓库定义的需求、开发、验证、Git、AgentLoop 编排与恢复流程制作成可安装的 Codex 插件。
- 预期效果：在 Codex App 内通过插件启动和持续执行完整流程，无需外部常驻服务。
- 完成标准：插件内置完整流程资料；提供初始化、校验、状态迁移、Gate 和状态查询工具；Hooks 能按运行状态约束编辑与结束；插件、Skill、脚本和示例均通过验证。
- 假设或约束：保留仓库 YAML/JSON Schema 协议作为事实源；不引入 MCP、App Server、数据库或常驻进程；首次安装后需在 Codex 中信任 Hooks。
