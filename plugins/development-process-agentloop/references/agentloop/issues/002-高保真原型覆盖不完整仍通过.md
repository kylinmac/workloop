# 高保真原型覆盖不完整仍通过

## 现象

01–09 页面范围只保存两页截图，自动化没有原型对比，仍被标记 passed。

## 影响

大部分页面的结构、视觉和交互偏差直到人工 completion Gate 才暴露。

## 根因

原型没有逐页实现矩阵，Evidence 只证明页面可打开；`visual` 是标签，不是机器可检查的覆盖契约。

## 旧门禁为何没拦截

Gate 没有计算“声明原型页 → flow 覆盖 → Evidence”的集合差。

## 修复

增加原型矩阵、固定视口、参考/实现文件、DOM/截图比较、逐行 coverage 和完整集合校验。

## 回归

三个高保真 HTML 只覆盖一个页面且 automation 指向 Markdown 时，必须拒绝进入 verified。

## 预防规则

视觉验证按声明范围做闭集覆盖；页面、交互或证据少一项都失败。
