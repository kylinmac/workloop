# AgentLoop 问题档案

每次修复 AgentLoop 协议、Schema、控制程序、插件安装或 Gate 漏洞时，必须新增一份问题文档，不得覆盖旧记录。文件按序号命名，一份只记录一个可独立回归的问题。

每份文档必须包含：现象、影响、根因、旧门禁为何没拦截、修复、回归、预防规则。修复提交可在完成后补充。
