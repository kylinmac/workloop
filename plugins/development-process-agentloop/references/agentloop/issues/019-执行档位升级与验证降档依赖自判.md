# 执行档位升级与验证降档依赖自判

## 现象
档位和验证策略有文字边界，但资格项没有结构化结果。
## 影响
复杂需求可误留在 trivial，或高风险需求误用 self_check。
## 根因
只保存最终选择和自然语言理由。
## 旧门禁为何没拦截
门禁仅校验 trivial 使用 quick-change，没有核对风险、并发和交付单元事实。
## 修复
新版 Loop 保存档位资格项；路由和转换按项目禁止标签及事实检查升级和 self_check。
## 回归
存在禁止标签、多交付单元或不确定结果时 self_check 必须失败。
## 预防规则
档位规则新增条件时同步更新资格 Schema 与路由 guard。
